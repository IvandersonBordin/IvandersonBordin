## 🎮 Projeto em destaque

### [Handkerchief Vita](https://github.com/IvandersonBordin/handkerchief-vita)

Projeto de pesquisa para um **port nativo de *Handkerchief* para o PlayStation Vita**.

- Engenharia reversa do jogo original para Windows (x86) e dos arquivos de dados HDK
- Protótipos em C com **VitaSDK**, testados no console
- Ferramentas em Python para inspecionar e visualizar os dados do jogo
- Desenvolvimento assistido por IA com **Claude Code**

> 🚧 Em andamento: ainda não é um port jogável completo.
